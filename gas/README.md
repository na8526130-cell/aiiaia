# 海斗tube (KaitoTube) - Google Apps Script (GAS) 版 導入手順書

本フォルダには、Google Apps Script (GAS) のウェブアプリとして「海斗tube」をサーバー代完全無料で公開・運用するための完全パッケージが格納されています。

UI・表記・デザイン・機能（動画検索、急上昇、ショート動画、コメント、チャンネル、ライブラリ、Educationプレイヤー、AI要約、API設定など）はすべて通常版と一切変わりません。

---

## 📦 同梱ファイル

1. **`Code.gs`**
   - GAS サーバー側スクリプト（YouTube Data API通信、Invidiousフォールバック、Gemini AI要約、Educationパラメータ中継、Web App エントリーポイント `doGet` / `doPost` を実装）。
2. **`index.html`**
   - React 19 + Tailwind CSS のUI・ロジックを完全単一ファイルにインラインバンドルしたHTML。GASの `HtmlService` でそのまま配信されます。
3. **`appsscript.json`**
   - Apps Script の設定マニフェストファイル（タイムゾーン、外部HTTP通信スコープ）。

---

## 🚀 デプロイ手順（所要時間：約2分）

### ステップ 1: 新規 Google Apps Script プロジェクトを作成
1. ブラウザで [Google Apps Script (script.google.com)](https://script.google.com/) にアクセスします。
2. 左上の **「新しいプロジェクト」** をクリックします。
3. プロジェクト名（例: `海斗tube`）を設定します。

### ステップ 2: スクリプトとHTMLをコピー＆ペースト
1. エディタ内の既存の `コード.gs`（または `Code.gs`）を開き、本フォルダの **`gas/Code.gs` の内容をすべて貼り付け** て保存します。
2. 左メニューの **「ファイル」横の「＋」アイコン** をクリックし、**「HTML」** を選択します。
3. ファイル名を **`index`** （拡張子の `.html` は入力不要）にします。
4. 作成された `index.html` の中身を、本フォルダの **`gas/index.html` の内容ですべて上書き貼り付け** して保存します。

*(任意) マニフェストファイルの更新:*
- 左側「歯車アイコン（プロジェクトの設定）」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れます。
- エディタに戻り `appsscript.json` を本フォルダの `gas/appsscript.json` の内容で上書き保存します。

### ステップ 3: スクリプトプロパティの設定（APIキー・任意）
*※YouTube Data API v3キーやGemini APIキーをGASサーバー側に持たせたい場合のみ設定します。設定しなくても、Invidious通信やアプリ内の「API設定」画面から利用可能です。*

1. 左メニューの **「プロジェクトの設定（歯車アイコン）」** を開きます。
2. 画面下部の **「スクリプト プロパティ」** セクションで **「スクリプト プロパティを追加」** をクリックします。
3. 以下のプロパティを追加して保存します:
   - プロパティ: `YOUTUBE_API_KEY` / 値: `(あなたのYouTube APIキー)`
   - プロパティ: `GEMINI_API_KEY` / 値: `(あなたのGemini APIキー・AI要約用)`

### ステップ 4: ウェブアプリとしてデプロイ
1. 画面右上の青い **「デプロイ」** ボタンをクリックし、**「新しいデプロイ」** を選択します。
2. 左側の歯車アイコン（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
3. 各項目を以下のように設定します:
   - **説明**: `v1.0` （任意）
   - **次のユーザーとして実行**: **自分** (`user@gmail.com`)
   - **アクセスできるユーザー**: **全員** (`Anyone`)
4. **「デプロイ」** をクリックします。
5. 初回は「アクセスを承認」画面が表示されるので、ご自身のGoogleアカウントを選択し、権限を承認します。
6. 発行された **「ウェブアプリ URL」**（`https://script.google.com/macros/s/.../exec`）を開くと、海斗tubeがそのまま起動します！

## 🔄 今後コードを更新・再ビルドする場合

本リポジトリ側でソースコードを変更した場合、以下のコマンドを実行すると `gas/index.html` が自動的に再生成されます。

```bash
npm run build:gas
```

生成された `gas/index.html` の中身を、GASプロジェクトの `index.html` に再度貼り付けて「デプロイを管理」→「新バージョンとしてデプロイ」することで、最新状態に更新できます。
